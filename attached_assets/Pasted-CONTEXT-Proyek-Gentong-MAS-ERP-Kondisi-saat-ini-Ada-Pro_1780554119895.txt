=== BAGIAN A: PRODUK LENGKAP ===

Pastikan ProductService punya semua fitur ini:

a) Produk Varian:
   Tambah model jika belum ada:
   model ProductVariant {
     id         String  @id @default(cuid())
     productId  String
     sku        String  @unique
     name       String  // misal: "Merah - XL"
     attributes Json    // { warna: "Merah", ukuran: "XL" }
     price      Float?
     stock      Float   @default(0)
     barcode    String?
   }
   Endpoint:
   GET    /api/inventory/products/:id/variants
   POST   /api/inventory/products/:id/variants
   PUT    /api/inventory/products/:id/variants/:variantId
   DELETE /api/inventory/products/:id/variants/:variantId

     id          String @id @default(cuid())

     componentId String  // produk komponen
     qty         Float
   }
   Endpoint:
   GET    /api/inventory/products/:id/bundle-components
   POST   /api/inventory/products/:id/bundle-components

c) Harga Bertingkat (Tiered Pricing):

     id        String @id @default(cuid())

     currency  String @default("IDR")
   }
   Endpoint:
   GET    /api/inventory/products/:id/tier-prices
   POST   /api/inventory/products/:id/tier-prices

Pastikan endpoint lengkap:

GET    /api/inventory/transfers

POST   /api/inventory/transfers/:id/cancel
