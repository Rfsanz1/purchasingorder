=== BAGIAN A: INVOICE ===

1. Lengkapi InvoiceService dengan method yang belum ada:

a) Recurring Invoice:
   - Tambah model InvoiceRecurring jika belum ada:
     model InvoiceRecurring {
       id          String   @id @default(cuid())
       invoiceId   String
       frequency   String   // "daily","weekly","monthly","yearly"
       startDate   DateTime
       endDate     DateTime?
       nextRunDate DateTime
       isActive    Boolean  @default(true)
     }
   - Endpoint: POST /api/invoices/:id/set-recurring
   - Endpoint: DELETE /api/invoices/:id/recurring
   - Cron job: setiap hari jam 00.00 cek InvoiceRecurring yang nextRunDate <= hari ini,
     duplikat invoice tersebut, update nextRunDate ke periode berikutnya

b) Invoice Reminder:
   - Tambah field reminderDays Int[] di Invoice (misal: [3, 7, 14] hari sebelum/sesudah jatuh tempo)
   - Cron job harian: cek invoice overdue atau mau jatuh tempo → kirim notifikasi
   - Endpoint: POST /api/invoices/:id/send-reminder (manual trigger)

c) Payment Link:
   - Tambah model PaymentLink (sudah ada referensi di schema? cek dulu)
   - Endpoint: POST /api/invoices/:id/payment-link
   - Body: { provider: "midtrans"|"xendit", expiredHours: 24 }
   - Return: { paymentUrl, token, expiredAt }
   - Endpoint GET /api/payment/:token (PUBLIC, no auth) → cek status payment

d) Print PDF:
   - Endpoint: GET /api/invoices/:id/pdf
   - Generate PDF menggunakan puppeteer atau @react-pdf/renderer
   - Template: logo perusahaan (dari settings), nama perusahaan, alamat, NPWP
     header invoice: nomor, tanggal, jatuh tempo, termin
     tabel item: no, produk, deskripsi, qty, satuan, harga, diskon, pajak, subtotal
     footer: subtotal, diskon global, pajak total, grand total
     tanda tangan: nama penandatangan, jabatan (dari settings template)
     pesan footer

e) Kirim WhatsApp:
   - Endpoint: POST /api/invoices/:id/send-whatsapp
   - Body: { phone: string, message?: string }
   - Format WA: "Halo [nama customer], berikut invoice [nomor] senilai [jumlah] jatuh tempo [tanggal]. [link payment]"
