# 🔄 PROMPT KONVERSI — Laravel PHP → NestJS + Prisma + Next.js

> Gunakan prompt ini untuk mengkonversi seluruh backend Laravel menjadi arsitektur modern yang sudah ada di folder `apps/` (NestJS backend + Next.js frontend).

---

## 🎯 TUJUAN

Konversi semua logic dari **Laravel 12 (PHP)** ke **NestJS 11 (TypeScript)** mengikuti pola arsitektur yang sudah ada di `apps/backend/`, dengan database layer menggunakan **Prisma ORM**, dan frontend menggunakan **Next.js 14 + TailwindCSS**.

---

## 🏗️ PERBANDINGAN ARSITEKTUR

| Komponen | Laravel (LAMA) | NestJS/Prisma (BARU) |
|---|---|---|
| Framework | Laravel 12 (PHP) | NestJS 11 (TypeScript) |
| ORM | Eloquent + Migration | Prisma ORM + `schema.prisma` |
| Auth | Sanctum (token) | JWT + Passport (`JwtAuthGuard`) |
| Database | PostgreSQL/MySQL | PostgreSQL via Prisma |
| Frontend | Blade + Vite | Next.js 14 + TailwindCSS |
| State Mgmt | Session | Zustand (frontend) |
| Port | 8000 | 4000 (backend), 3000 (frontend) |
| Package Mgmt | Composer + npm | pnpm workspaces |

```
routes/api.php (Route::get...)      → @Get(), @Post() decorator di controller
```

### Contoh pola module NestJS yang HARUS diikuti:

```typescript
// {nama}.module.ts
import { Module } from '@nestjs/common';
import { XController } from './x.controller.js';
import { XService } from './x.service.js';
import { PrismaService } from '../../database/prisma.service.js';

@Module({
  controllers: [XController],
  providers: [XService, PrismaService],
  exports: [XService],
})
export class XModule {}

// {nama}.controller.ts
import { Controller, Get, Post, Put, Delete, Param, Body, Query, Inject, UseGuards } from '@nestjs/common';
import { XService } from './x.service.js';
import { JwtAuthGuard } from '../../common/guards/jwt-auth.guard.js';

@Controller('x')
@UseGuards(JwtAuthGuard)
export class XController {
  constructor(@Inject(XService) private readonly svc: XService) {}

  @Get() getAll(@Query() q: any) { return this.svc.getAll(q); }
  @Get(':id') getOne(@Param('id') id: string) { return this.svc.getOne(id); }
  @Post() create(@Body() dto: any) { return this.svc.create(dto); }
  @Put(':id') update(@Param('id') id: string, @Body() dto: any) { return this.svc.update(id, dto); }
  @Delete(':id') remove(@Param('id') id: string) { return this.svc.remove(id); }
}

// {nama}.service.ts
import { Inject, Injectable, NotFoundException } from '@nestjs/common';
import { PrismaService } from '../../database/prisma.service.js';

@Injectable()
export class XService {
  constructor(@Inject(PrismaService) private readonly prisma: PrismaService) {}

  async getAll(query: any) {
    const { search, page = 1, limit = 20 } = query;
    const skip = (Number(page) - 1) * Number(limit);
    const where: any = {};
    if (search) where.name = { contains: search, mode: 'insensitive' };
    const [data, total] = await Promise.all([
      this.prisma.x.findMany({ where, skip, take: Number(limit), orderBy: { createdAt: 'desc' } }),
      this.prisma.x.count({ where }),
    ]);
    return { data, total, page: Number(page), totalPages: Math.ceil(total / Number(limit)) };
  }

  async getOne(id: string) {
    const item = await this.prisma.x.findUnique({ where: { id } });
    if (!item) throw new NotFoundException('Data tidak ditemukan');
    return item;
  }

  async create(dto: any) { return this.prisma.x.create({ data: dto }); }
  async update(id: string, dto: any) { return this.prisma.x.update({ where: { id }, data: dto }); }
  async remove(id: string) { return this.prisma.x.delete({ where: { id } }); }
}
```

```typescript
// Nomor PO otomatis — sama persis dengan Laravel
async generatePONumber(): Promise<string> {
  const year = new Date().getFullYear();
  const month = String(new Date().getMonth() + 1).padStart(2, '0');
  const latest = await this.prisma.purchaseOrder.findFirst({
    where: {
      createdAt: {
        gte: new Date(`${year}-${month}-01`),
        lt: new Date(month === '12' ? `${year+1}-01-01` : `${year}-${String(Number(month)+1).padStart(2,'0')}-01`),
      },
    },
    orderBy: { createdAt: 'desc' },
  });
  const seq = latest ? Number(latest.noPo.split('/')[3]) + 1 : 1;
  return `PO/${year}/${month}/${String(seq).padStart(4, '0')}`;
}

// Kalkulasi otomatis (subtotal, diskon, PPN 11%, total)
async createPurchaseOrder(dto: any) {
  const { items, discountPercentage = 0, ...poData } = dto;
  const subtotal = items.reduce((sum: number, item: any) => sum + (item.qty * item.hargaBeli), 0);
  const discount = subtotal * (discountPercentage / 100);
  const tax = (subtotal - discount) * 0.11;  // PPN 11%
  const totalHarga = subtotal - discount + tax;
  const noPo = await this.generatePONumber();
  return this.prisma.purchaseOrder.create({
    data: {
      ...poData, noPo, totalHarga,
      items: { create: items },
    },
    include: { supplier: true, items: { include: { product: true } } },
  });
}

// Approve PO
async approvePurchaseOrder(id: string, userId: string) {
  return this.prisma.purchaseOrder.update({
    where: { id },
    data: { status: 'approved', approvedBy: userId, approvedAt: new Date() },
  });
}

// Status flow: draft → sent → approved → partial → received / cancelled
async changeStatus(id: string, status: string) {
  const allowed = ['sent', 'approved', 'partial', 'received', 'cancelled'];
  if (!allowed.includes(status)) throw new Error('Status tidak valid');
  return this.prisma.purchaseOrder.update({ where: { id }, data: { status } });
}
```

```typescript
// Update stok produk
async updateStok(id: string, qty: number, type: 'in' | 'out', note?: string) {
  const product = await this.prisma.product.findUnique({ where: { id } });
  if (!product) throw new NotFoundException('Produk tidak ditemukan');
  const newStok = type === 'in' ? product.stok + qty : product.stok - qty;
  await Promise.all([
    this.prisma.product.update({ where: { id }, data: { stok: newStok } }),
    this.prisma.stockMovement.create({
      data: { productId: id, type, qty, note: note ?? '' },
    }),
  ]);
  return { stok: newStok };
}
```

```typescript
// kledo.service.ts
import { Inject, Injectable } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { PrismaService } from '../../database/prisma.service.js';
import { firstValueFrom } from 'rxjs';

@Injectable()
export class KledoService {
  private readonly baseUrl = 'https://api.kledo.com/v3';
  private get headers() {
    return { Authorization: `Bearer ${process.env.KLEDO_TOKEN}` };
  }

  constructor(
    @Inject(PrismaService) private readonly prisma: PrismaService,
    @Inject(HttpService) private readonly http: HttpService,
  ) {}

  async getContacts() {
    const { data } = await firstValueFrom(
      this.http.get(`${this.baseUrl}/contacts`, { headers: this.headers })
    );
    return data;
  }

  async getProducts() {
    const { data } = await firstValueFrom(
      this.http.get(`${this.baseUrl}/products`, { headers: this.headers })
    );
    return data;
  }

  async getProductsWithStock() {
    const { data } = await firstValueFrom(
      this.http.get(`${this.baseUrl}/products?include=stock`, { headers: this.headers })
    );
    return data;
  }

  async syncProducts() {
    const log = await this.prisma.kledoSyncLog.create({
      data: { type: 'products', status: 'running' }
    });
    try {
      const products = await this.getProducts();
      // Update produk lokal dari Kledo
      for (const p of products.data ?? []) {
        await this.prisma.product.upsert({
          where: { sku: p.code ?? p.id.toString() },
          update: { kledoProductId: p.id.toString(), hargaKledo: p.price ?? 0 },
          create: {
            sku: p.code ?? p.id.toString(),
            name: p.name,
            kledoProductId: p.id.toString(),
            hargaKledo: p.price ?? 0,
          },
        });
      }
      await this.prisma.kledoSyncLog.update({
        where: { id: log.id },
        data: { status: 'success', message: `${products.data?.length ?? 0} produk disync` }
      });
    } catch (err: any) {
      await this.prisma.kledoSyncLog.update({
        where: { id: log.id },
        data: { status: 'error', message: err.message }
      });
      throw err;
    }
  }

  async autoSync() {
    await Promise.allSettled([
      this.syncProducts(),
    ]);
    return { message: 'Auto sync selesai' };
  }
}
```

```typescript
async createJournalEntry(dto: any) {
  const { lines, ...entryData } = dto;

    data: {
      ...entryData,
      lines: { create: lines },

async getCashFlow(query: any) {
  const { dateFrom, dateTo } = query;
  const where: any = {};
  if (dateFrom && dateTo) {
    where.createdAt = { gte: new Date(dateFrom), lte: new Date(dateTo) };
  }
  const [masuk, keluar] = await Promise.all([
    this.prisma.cashTransaction.aggregate({
      where: { ...where, type: 'in' }, _sum: { amount: true },
    }),
    this.prisma.cashTransaction.aggregate({
      where: { ...where, type: 'out' }, _sum: { amount: true },
    }),
  ]);
  return {
    totalMasuk: masuk._sum.amount ?? 0,
    totalKeluar: keluar._sum.amount ?? 0,
    saldo: Number(masuk._sum.amount ?? 0) - Number(keluar._sum.amount ?? 0),
  };
}
```

```typescript
async sendWhatsApp(target: string, message: string) {
  if (!process.env.FONNTE_TOKEN) return { skipped: true };
  const resp = await fetch('https://api.fonnte.com/send', {
    method: 'POST',
    headers: { Authorization: process.env.FONNTE_TOKEN },
    body: JSON.stringify({ target, message }),
  });
  const result = await resp.json();
  await this.prisma.notification.create({
    data: {
      recipient: target,
      title: 'WhatsApp',
      message,
      status: result.status ? 'sent' : 'failed',
    },
  });
  return result;
}
```

```typescript
// apps/frontend/app/purchasing/page.tsx
'use client';
import { useState, useEffect } from 'react';
import { useAuthStore } from '../../lib/store/useAuthStore';
import api from '../../lib/api';

interface PurchaseOrder {
  id: string;
  noPo: string;
  supplier: { name: string };
  tanggal: string;
  totalHarga: number;
  status: string;
}

export default function PurchasingPage() {
  const [orders, setOrders] = useState<PurchaseOrder[]>([]);
  const [loading, setLoading] = useState(true);
  const token = useAuthStore((s) => s.token);

  useEffect(() => {
    api.get('/purchasing/purchase-orders', {
      headers: { Authorization: `Bearer ${token}` },
    })
    .then((res) => setOrders(res.data.data))
    .finally(() => setLoading(false));
  }, [token]);

  const formatRupiah = (n: number) =>
    new Intl.NumberFormat('id-ID', { style: 'currency', currency: 'IDR' }).format(n);

  const statusColor: Record<string, string> = {
    draft: 'bg-gray-100 text-gray-700',
    sent: 'bg-blue-100 text-blue-700',
    approved: 'bg-green-100 text-green-700',
    partial: 'bg-yellow-100 text-yellow-700',
    received: 'bg-emerald-100 text-emerald-700',
    cancelled: 'bg-red-100 text-red-700',
  };

  return (
    <div className="p-6">
      <div className="flex items-center justify-between mb-6">
        <h1 className="text-2xl font-bold text-gray-900">Purchase Order</h1>
        <button className="bg-blue-600 text-white px-4 py-2 rounded-lg hover:bg-blue-700">
          + Buat PO
        </button>
      </div>

      {loading ? (
        <div className="text-center py-10 text-gray-500">Memuat data...</div>
      ) : (
        <div className="bg-white rounded-xl shadow overflow-hidden">
          <table className="min-w-full divide-y divide-gray-200">
            <thead className="bg-gray-50">
              <tr>
                {['No. PO', 'Supplier', 'Tanggal', 'Total', 'Status', 'Aksi'].map((h) => (
                  <th key={h} className="px-6 py-3 text-left text-xs font-semibold text-gray-500 uppercase">
                    {h}
                  </th>
                ))}
              </tr>
            </thead>
            <tbody className="divide-y divide-gray-100">
              {orders.map((po) => (
                <tr key={po.id} className="hover:bg-gray-50">
                  <td className="px-6 py-4 font-mono text-sm font-medium text-blue-600">{po.noPo}</td>
                  <td className="px-6 py-4 text-sm text-gray-900">{po.supplier.name}</td>
                  <td className="px-6 py-4 text-sm text-gray-600">
                    {new Date(po.tanggal).toLocaleDateString('id-ID')}
                  </td>
                  <td className="px-6 py-4 text-sm font-medium">{formatRupiah(Number(po.totalHarga))}</td>
                  <td className="px-6 py-4">
                    <span className={`px-2 py-1 rounded-full text-xs font-medium ${statusColor[po.status] ?? ''}`}>
                      {po.status}
                    </span>
                  </td>
                  <td className="px-6 py-4 text-sm">
                    <button className="text-blue-600 hover:underline mr-3">Detail</button>
                    {po.status === 'draft' && (
                      <button className="text-green-600 hover:underline">Approve</button>
                    )}
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      )}
    </div>
  );
}
```

## 🔑 ATURAN KONVERSI PENTING

1. **ID**: Laravel pakai `integer` autoincrement → NestJS/Prisma pakai `String @id @default(uuid())`
2. **Nama field**: Laravel `snake_case` (`po_number`) → Prisma `camelCase` (`noPo`)
3. **Soft delete**: Laravel `SoftDeletes` trait → Prisma tidak ada built-in, gunakan field `deletedAt DateTime?` + filter `where: { deletedAt: null }`
4. **Validation**: Laravel `$request->validate([...])` → NestJS gunakan `class-validator` di DTO, atau validasi manual di service
5. **Response format**: Laravel `return $this->success($data, 'msg')` → NestJS return object langsung, NestJS otomatis wrap jadi JSON
6. **Auth**: Laravel `auth()->user()` → NestJS `@CurrentUser() user: any` dari JWT payload
7. **Exception**: Laravel `abort(404)` → NestJS `throw new NotFoundException('...')`
8. **Bahasa**: Semua pesan error & label UI tetap dalam **Bahasa Indonesia**

---

*Konversi ini mempertahankan 100% business logic yang sama, hanya mengubah bahasa pemrograman dan framework dari PHP/Laravel ke TypeScript/NestJS sesuai arsitektur modern di folder `apps/`.*
