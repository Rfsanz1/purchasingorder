📋 PERINTAH IMPLEMENTASI PER MODUL
Untuk setiap modul baru, jalankan urutan ini:
bash# 1. Update Prisma schema
# Edit: apps/backend/prisma/schema.prisma
# Tambahkan model-model di atas

# 2. Generate Prisma client
cd apps/backend
pnpm prisma generate

# 3. Migrasi database
pnpm prisma migrate dev --name "add_{nama}_module"

# 4. Buat file module
mkdir -p src/modules/{nama}
touch src/modules/{nama}/{nama}.module.ts
touch src/modules/{nama}/{nama}.controller.ts
touch src/modules/{nama}/{nama}.service.ts

# 5. Register di app.module.ts
# Import dan tambahkan ke imports[]

# 6. Buat halaman frontend
mkdir -p apps/frontend/app/{nama}
touch apps/frontend/app/{nama}/page.tsx
