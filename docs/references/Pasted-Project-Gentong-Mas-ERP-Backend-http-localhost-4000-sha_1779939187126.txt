APP 1: POS App — apps/pos-app
Port: 3004
Role: Kasir, Supervisor Kasir
Warna tema: emerald/green (#059669)
══════════════════════════════════

Config:
- Port default 3004
- Middleware: block jika role bukan Kasir/Supervisor

Komponen di apps/pos-app/components/:
- POSLayout.tsx   (layout khusus POS, no sidebar)
- ProductGrid.tsx (grid produk dengan gambar)
- Cart.tsx        (keranjang belanja kanan)
- PaymentModal.tsx (modal proses pembayaran)
- Receipt.tsx     (struk digital/print)

Halaman:

/login
   - Login kasir
   - Setelah login → langsung ke sesi kasir aktif atau /sessions

/sessions — Kelola Sesi
   - Tampilkan sesi aktif jika ada → tombol "Lanjut"
   - Jika tidak ada → tombol "Buka Sesi Baru" (input kas awal)
   - List sesi sebelumnya + total per sesi

/sessions/[id] — Detail/Tutup Sesi
   - Rekap: total transaksi, total kas masuk, metode bayar
   - Tombol: Tutup Sesi (input kas akhir)
   - Print laporan sesi

/ — Layar Kasir Utama (halaman terpenting)
   Layout 2 panel:
   Panel KIRI (60%):
   - Search bar produk (autocomplete)
   - Filter kategori (tabs horizontal)
   - Grid produk (gambar, nama, harga)
   - Klik produk → masuk keranjang

   Panel KANAN (40%):
   - List item di keranjang (nama, qty stepper, subtotal)
   - Field: kode voucher/diskon
   - Field: cari member pelanggan
   - Subtotal, diskon, pajak, TOTAL BESAR
   - Tombol BAYAR (hijau besar)

   Modal BAYAR:
   - Pilih metode: Tunai / Transfer / Kartu / QRIS
   - Jika tunai: input nominal → tampilkan kembalian
   - Tombol: Konfirmasi Pembayaran → cetak struk

/orders — Riwayat Transaksi
   - Tabel transaksi hari ini + semua history
   - Filter: tanggal, kasir, metode bayar
   - Klik → detail + tombol reprint struk

/products — Produk POS
   - Tabel produk yang aktif di POS
   - Edit harga, aktif/nonaktif produk di POS
   - Hanya Supervisor yang bisa edit

/reports — Laporan Kasir
   - Ringkasan hari ini: omzet, jumlah transaksi, rata-rata
   - Breakdown per metode pembayaran
   - Grafik penjualan per jam

APP 2: Driver App — apps/driver-app
Port: 3005
Role: Driver
Warna tema: slate (#475569)
══════════════════════════════════

PENTING — Mobile-first:
- Desain untuk layar HP (max-width 430px)
- Bottom navigation bar (bukan sidebar)
- Tombol aksi besar dan mudah dipencet

Config:
- Port default 3005
- Middleware: block jika role bukan Driver

Halaman:

/login
   - Login driver (form sederhana, besar)
   - Error jika bukan role Driver

/ — Dashboard Driver
   - Greeting: "Halo [nama], ada [X] pengiriman hari ini"
   - Cards: Menunggu, Dalam Perjalanan, Selesai Hari Ini
   - List pengiriman hari ini (preview singkat)
   - Tap item → langsung ke detail

/deliveries — Semua Pengiriman
   - Tab: Hari Ini | Mendatang | Selesai
   - List card per pengiriman:
     nama penerima, alamat singkat, status badge
   - Pull to refresh

/delivery/[id] — Detail Pengiriman (sudah ada, lengkapi)
   Tampilkan:
   - Nama & no HP penerima (tap HP → buka dialer)
   - Alamat lengkap (tap → buka Google Maps)
   - List barang yang dikirim
   - Status timeline: Assigned → Berangkat → Tiba → Selesai

   Tombol aksi berdasarkan status:
   - Status "assigned"    → tombol "🚀 Mulai Berangkat"
   - Status "on_the_way"  → tombol "📍 Saya Sudah Tiba"
   - Status "arrived"     → tombol "✅ Selesai Diantar"
                            + upload foto bukti (wajib)
   - Jika gagal antar     → tombol "❌ Gagal Antar"
                            + form alasan (pilihan + catatan)

/history — Riwayat Selesai
   - List pengiriman selesai semua waktu
   - Filter bulan

/profile — Profil Driver
   - Nama, foto, no HP, kendaraan
   - Tombol: Edit Profil, Ganti Password, Logout

Bottom Navigation:
   [🏠 Beranda] [📦 Tugas] [📋 Riwayat] [👤 Profil]

Semua update status panggil PATCH /delivery/[id]/status
dengan body { status, notes?, photo? }.
